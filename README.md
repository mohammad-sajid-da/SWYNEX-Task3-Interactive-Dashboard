# SWYNEX - Task 3: Interactive Sales & Customer Analytics Dashboard

## Project Overview
This repository contains the interactive business intelligence dashboard developed for Task 3 of the Swynex Technologies Data Analytics Internship. Built using Power BI Desktop, the dashboard integrates summary KPIs, multi-dimensional slicers, and interactive visuals to explore customer distribution, purchasing patterns, and sales trends across 124 customer records.

---

## Key Performance Indicators (KPIs)
* **Total Customers:** 124 distinct customers
* **Total Revenue:** ₹422.36K
* **Average Order Value (AOV):** ₹3.41K

---

## Interactive Features & Slicers
* **City Filter:** Dynamic dropdown to isolate metrics across major metropolitan centers (e.g., Varanasi, Kolkata, Delhi, Bengaluru, Mumbai).
* **Gender Filter:** Dropdown slicer to examine demographic purchasing patterns.
* **Year Filter:** Dropdown filter to evaluate annual performance (2021–2024).

---

## Dashboard Visualizations & Insights
1. **City-Wise Customers (Horizontal Bar Chart):** Highlights regional penetration, showing top customer counts in Kolkata, Varanasi, and Delhi.
2. **City-Wise Revenue (Column Chart):** Clearly highlights the revenue impact of Varanasi, driven by high-value transactions.
3. **Category-Wise Revenue (Pie / Share Visual):** Breaks down category contribution, showing strong shares across Groceries, Books, and Clothing.
4. **Year-Wise Performance (Trend & Volume Charts):** Tracks customer acquisition volume and annual revenue progression from 2021 through 2024.
